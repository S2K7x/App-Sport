Le levier de récup n°1. La fatigue périphérique et nerveuse générée par les isométries (planche, HSPU) se résorbe surtout pendant le sommeil profond.
Shabbat — repos complet
Le seul jour sans entraînement, placé pile avant la séance la plus lourde (dimanche). Pas de rattrapage ni de "petite séance" : c'est ce repos qui rend 6 jours d'entraînement soutenables.
Course et calisthénie — jamais collées
Si tu dois faire les deux le même jour, laisse au moins 6 h d'écart : l'interférence est plus forte quand les deux sont dans la même séance.
Protéine avant coucher — 30-40 g
Caséine/whey ou skyr avant dodo, favorise la synthèse protéique nocturne. La quantité totale/jour reste plus importante que le timing exact.
Deload — 1 semaine toutes les 5-6 semaines
Réduire le volume d'environ 40-50 % (moins de séries, pas de lest ajouté, holds à 60-70 % du max). Ne saute pas le geste, allège-le — ça évite le plateau et protège tendons/poignets.

Pourquoi pas de synchro automatique ?Ce qu'une web app peut faire sur iPhone

Apple Santé n'est pas accessible depuis une web app. HealthKit est réservé aux apps natives de l'App Store : il n'existe aucune API web, même pour une app installée sur l'écran d'accueil.

Garmin et adidas Running n'ouvrent pas leurs données aux particuliers. Les API Garmin sont réservées aux entreprises validées dans son programme développeur, et adidas Running n'a pas d'API publique.

La solution : Apple Santé comme point central. Garmin Connect et adidas Running y écrivent tes activités. Un Raccourci iOS les relit et les passe à l'app par le presse-papiers. Un lien ne marcherait pas : l'app installée a un stockage séparé de Safari. Rien ne quitte ton téléphone.

1. Envoyer Garmin et adidas vers SantéUne fois, dans chaque app
  1. Garmin Connect : Réglages → Apps connectées → Apple Santé → active le partage. Garmin Connect doit être ouvert de temps en temps pour envoyer les données.
  2. adidas Running : Profil → roue dentée → Comptes partenaires → Apple Santé.

Si une même course est enregistrée par les deux apps, elle n'apparaît qu'une fois ici : même type et départ à moins de 3 minutes d'écart = même activité.

2. Créer le Raccourci~5 min, une seule fois
  1. App Raccourcis → + → nomme-le « Synchro Planche OS ».
  2. Ajoute Rechercher des échantillons de santé : type Entraînements, filtre Date de début dans les 14 derniers jours.
  3. Ajoute Répéter avec chaque élément.
  4. Dans la boucle, ajoute Dictionnaire avec ces clés, chacune reliée à une propriété de l'Élément répété : type (Type), start (Date de début — touche la variable et choisis le format ISO 8601), duration (Durée), distance (Distance), energy (Énergie), source (Source).
  5. Après la boucle : Copier dans le presse-papiers les Résultats de Répéter.
  6. Lance-le, ouvre Planche OS → Réglages → Coller depuis Raccourcis.

Les noms de propriétés varient un peu selon la version d'iOS ; l'app accepte les clés en français ou en anglais, et les valeurs avec unités (« 5,02 km », « 32 min »).

Optionnel — récupération : refais les étapes 2 à 4 avec Fréquence cardiaque au repos (clés type = texte « repos », start, value = Valeur), puis combine les deux listes avec Ajouter à la variable avant de copier. L'app compare ta FC de repos sur 7 jours à celle des semaines précédentes.

Astuce : ajoute le Raccourci à l'écran d'accueil, à côté de l'app.

Importer tout l'historiqueExport Santé ou fichiers GPX

Export Apple Santé : Santé → ta photo → Exporter toutes les données de santé → Enregistrer dans Fichiers. Touche le .zip pour le décompresser, puis ici Importer un fichier → apple_health_export/export.xml. L'app garde les entraînements des 400 derniers jours, ta FC de repos et ta VFC. Le fichier peut peser plusieurs centaines de Mo : compte une minute.

GPX : exporte une activité en .gpx depuis Garmin Connect ou adidas Running, puis Importer un fichier (plusieurs fichiers d'un coup possible). Distance, durée et FC sont recalculées depuis la trace.
